디지로그쌤 홈페이지 — 수정·운영 안내

내용 고치기 (가장 쉬운 방법)
  https://digilog-website.vercel.app/admin 에 로그인해서 고치고 저장 → 1~2분 뒤 반영
  처음 설정: docs/관리자-설정방법.md

폴더 구조
  content/        페이지 문구·사진·목록 (관리자 화면이 고치는 파일)
  api/_data/      수업자료 목록과 비밀번호(암호화) — 방문자에게 안 보임
  static/         디자인(style.css), 동작(script.js), 사진(assets), 관리자 화면
  build.js        content + static → 실제 페이지(dist/) 만들기. Vercel이 배포 때 자동 실행
  api/            블로그 최신글, 수업자료 확인, 문의 저장, 관리자 기능

내 컴퓨터에서 미리보기
  node tools/dev-server.js  →  http://localhost:3000
  미리보기의 /admin 비밀번호: local-admin (내 컴퓨터 파일을 바로 고침)

문의 폼 → 구글 시트: docs/구글시트-연결방법.md (연결 완료)
