디지로그쌤 홈페이지 (멀티페이지) — 수정·운영 안내

페이지
  index.html     홈
  about.html     소개 (경력·자격·수업 철학)
  lectures.html  강의 분야
  projects.html  왕초탈 프로젝트 + 출강 이력
  reviews.html   강의후기 (현장 사진 + 블로그 출강후기 자동 목록)
  materials.html 수업자료실 (수업별 비밀번호)
  contact.html   강의 문의 폼 (구글 시트 저장)

자주 하는 수정
  - 메뉴 이름·순서: script.js 맨 위 NAV 목록 (모든 페이지에 한 번에 반영)
  - 색상: style.css 맨 위 :root (--coral 이 주 색상)
  - 출강 이력 추가: projects.html 의 <li> 한 줄 복사 후 내용 변경
  - 현장 사진: assets/field 폴더
  - 블로그 최신글: 블로그에 글을 올리면 자동으로 나타납니다 (30분 단위 갱신)

수업자료 추가
  1. node tools/hash-password.js 비밀번호   → 나온 긴 글자를 복사
  2. api/_lib/materials.js 에 수업 한 덩어리 추가 (파일 안 설명 참고)
  3. 자료는 구글 드라이브 공유 링크로 연결
  ※ 샘플 수업(비밀번호 digilog)은 실제 수업을 넣은 뒤 지워 주세요.

문의 폼 → 구글 시트
  docs/구글시트-연결방법.md 를 따라 한 번만 설정하면 됩니다.
  설정 전에는 "작성한 내용으로 메일 보내기"로 대신 동작합니다.

내 컴퓨터에서 미리보기
  node tools/dev-server.js  →  브라우저에서 http://localhost:3000
  (index.html 더블클릭으로는 메뉴·블로그·자료실이 동작하지 않습니다)
