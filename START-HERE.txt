디지로그쌤 프로필 웹사이트 — 실행 안내

1. 다운로드한 digilog-website.zip을 마우스 오른쪽 버튼으로 클릭합니다.
2. [압축 풀기] 또는 [모두 추출]을 선택합니다.
3. 압축을 푼 폴더 안의 index.html을 더블 클릭합니다.
4. Chrome 또는 Edge에서 페이지가 열립니다. 별도 설치나 가입은 필요 없습니다.
5. 오른쪽 위 BGM OFF를 누르면 음악이 시작됩니다. 다시 누르면 멈춥니다.

파일을 함께 보관하세요
index.html : 글과 링크, 페이지 구성
style.css : 색상, 글자 크기, PC·모바일 배치
script.js : 강의 탭, 문의 양식 복사, BGM
assets/no-heeseon-profile.webp : 첫 화면 보정 프로필 사진
assets/wangchotal.webp : 왕초탈 프로젝트 이미지

수정하기
index.html을 메모장 또는 코드 편집기로 열어 문구를 수정하고 저장한 뒤 브라우저를 새로고침합니다.
style.css 맨 위 --paper, --ink, --red가 주요 색상입니다.
문의 링크는 index.html의 contact 영역에 있습니다.
문의 채널은 heeseon.ai@gmail.com 이메일이며, 네이버 블로그 heeseon_ai를 함께 연결했습니다.
메일 주소 복사 버튼은 heeseon.ai@gmail.com을 복사합니다.
이메일로 강의 문의를 누르면 문의 항목이 적힌 메일 초안이 열립니다.
문의 양식은 메일 주소로 시작하며 인사말은 없습니다. 문의 양식 복사는 문의를 자동 전송하지 않습니다. 내용을 채워 이메일로 보내는 방식입니다.
로컬 파일에서 자동 복사가 제한되면 화면에 나타나는 문의 양식을 직접 복사할 수 있습니다.

사진과 내용 안내
첨부 이미지는 디자인 참고자료이므로 강의 현장 사진으로 사용하지 않았습니다.
첫 화면은 제공하신 노희선 프로필 사진의 색감을 조정한 이미지입니다.
강의 분야는 필요한 설명만 펼쳐 볼 수 있도록 간결하게 정리했습니다.
프로필 경력·자격은 제공하신 PDF와 요청하신 오늘두AI 경력을 바탕으로 정리했습니다. 영문 이름은 Roh Heeseon입니다. 학력 날짜가 상충하여 학력은 싣지 않았습니다.
왕초탈 프로젝트는 제공하신 교과서의 5강 커리큘럼과 원본 홍보 이미지의 보정본으로 구성했습니다.
BGM은 Web Audio로 재생하는 오리지널 앰비언트 시퀀스이며 별도 음악 파일이 없습니다.

온라인 게시와 로컬 실행의 차이
index.html을 여는 것은 내 컴퓨터에서 확인하는 방법입니다. 다른 사람이 내 파일 경로로 접속할 수는 없습니다.
함께 제공된 사이트 주소는 최초에는 본인만 접근할 수 있는 비공개 상태입니다.
다른 사람에게 공유하려면 사이트의 공개 범위를 먼저 변경해야 합니다.
HTML을 수정해도 이미 게시된 주소에는 자동 반영되지 않습니다. 수정 후 다시 게시해야 합니다.

확인 범위
HTML 내 파일·섹션 연결 및 JavaScript 문법을 점검했습니다.
PC·모바일 대응 CSS를 적용했으며, 실제 기기별 화면 및 음향 재생은 사용 중인 브라우저에서 확인해 주세요.
