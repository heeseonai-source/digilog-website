# 강의 문의 폼 → 구글 시트 연결 방법 (10분)

연결 전에는 문의 폼이 "메일로 보내기" 버튼으로 대신 동작합니다. 아래를 한 번만 해 두면 문의가 시트에 자동으로 쌓입니다.

## 1. 시트와 스크립트 만들기
1. 구글 드라이브에서 새 스프레드시트를 만듭니다. (이름 예: 홈페이지 강의 문의)
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기존 코드를 지우고 `docs/google-apps-script.gs` 내용을 붙여 넣습니다.
4. 맨 위 `SECRET` 을 아무도 모를 긴 글자로 바꿉니다. (예: digilog-문의-8f3k2)
5. 새 문의를 메일로도 받고 싶으면 `NOTIFY_EMAIL` 에 메일 주소를 넣습니다.
6. 저장(디스크 아이콘)합니다.

## 2. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 유형 선택(톱니바퀴) → **웹 앱**
3. 실행 계정: **나**, 액세스 권한: **모든 사용자**
4. **배포** → 권한 승인(내 구글 계정) → 나오는 **웹 앱 URL** 을 복사합니다. (`https://script.google.com/macros/s/.../exec`)

## 3. Vercel에 주소 넣기
1. vercel.com → digilog-website 프로젝트 → **Settings → Environment Variables**
2. 두 개를 추가합니다.
   - `SHEET_WEBHOOK_URL` = 복사한 웹 앱 URL
   - `SHEET_SECRET` = 1-4에서 정한 SECRET 값
3. **Deployments** 에서 최신 배포를 **Redeploy** 합니다.

## 4. 확인
홈페이지 문의 페이지에서 테스트 문의를 보내고 시트에 한 줄이 생기는지 봅니다.
스크립트를 고치면 **배포 → 배포 관리 → 수정(연필) → 새 버전** 으로 다시 배포해야 반영됩니다.

## 수강생 후기(메모) 연결 — 2026-11-18 추가

후기 메모도 문의와 같은 시트·같은 웹앱 주소(`SHEET_WEBHOOK_URL`)를 씁니다. 앱스 스크립트 코드만 새로 바꾸면 됩니다.

1. 시트 「홈페이지 강의 문의」 → 확장 프로그램 → Apps Script 를 엽니다.
2. 기존 코드를 모두 지우고 `docs/google-apps-script.gs` 내용을 붙여 넣은 뒤 저장합니다.
3. 배포 → **배포 관리** → 연필(수정) → 버전: **새 버전** → 배포. (새 배포를 만들면 주소가 바뀌므로 꼭 '배포 관리'에서 수정)
4. 처음 후기가 들어오면 시트에 「후기」 탭이 자동으로 생깁니다. 칸: 작성일시 · 수업 · 닉네임 · 내용 · 숨기기

- 메모는 남기는 즉시 홈페이지에 보입니다(1분 안팎 캐시).
- 내리고 싶은 메모는 「숨기기」 칸에 아무 글자나 적으면 사라집니다.
- 수강생이 고르는 수업 목록은 관리자 화면 → 수강생 후기 → 「후기 받을 수업」에서 바꿉니다.
- 스크립트를 업데이트하기 전에는 후기 쓰기가 "준비하고 있어요"로 막혀 있어, 문의 탭에 빈 줄이 생기지 않습니다.

## 수업 진도 바 연결 — 2026-11-23 추가

수업 페이지 맨 위 「오늘의 진도」 바도 같은 시트·같은 웹앱 주소(`SHEET_WEBHOOK_URL`)를 씁니다. 앱스 스크립트 코드만 새로 바꾸면 됩니다.

1. 시트 「홈페이지 강의 문의」 → 확장 프로그램 → Apps Script 를 엽니다.
2. 기존 코드를 모두 지우고 `docs/google-apps-script.gs` 내용을 붙여 넣은 뒤 저장합니다.
   (맨 위 `SECRET` 값은 지금 쓰고 있는 값과 똑같이 둡니다. 2026-11-12 배포본은 비워 둠)
3. 배포 → **배포 관리** → 연필(수정) → 버전: **새 버전** → 배포. (새 배포를 만들면 주소가 바뀌므로 꼭 '배포 관리'에서 수정)
4. 처음 진도를 바꾸면 시트에 「진도」 탭이 자동으로 생깁니다. 칸: 수업 ID · 단계 번호(0부터) · 단계 이름 · 바뀐 시각

수업 때 쓰는 법
- 강사 PC에서 먼저 `/admin` 에 로그인합니다. (7일 동안 유지)
- 수업 페이지를 열면 진도 바 아래에 「강사용」 버튼(◀ 이전 · 다음 단계 ▶ · 처음으로)이 보입니다. 단계를 직접 눌러도 그 단계로 옮겨집니다.
- 수강생 화면은 15초 안에 따라 움직입니다. 수강생에게는 강사용 버튼이 보이지 않습니다.
- 단계 이름·순서는 `api/_data/materials.json` 의 수업 항목 `progress` 에서 바꿉니다. (`p` 에 프롬프트 id를 넣으면 수강생이 그 단계를 눌러 해당 프롬프트로 이동)
- 스크립트를 업데이트하기 전에는 진도가 「아직 시작 전」으로만 보이고, 강사용 버튼을 누르면 "앱스 스크립트가 최신인지 확인" 안내가 나옵니다.
