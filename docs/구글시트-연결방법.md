# 강의 문의 폼 → 구글 시트 연결 방법 (10분)

연결 전에는 문의 폼이 "메일로 보내기" 버튼으로 대신 동작합니다. 아래를 한 번만 해 두면 문의가 시트에 자동으로 쌓입니다.

## 1. 시트와 스크립트 만들기
1. 구글 드라이브에서 새 스프레드시트를 만듭니다. (이름 예: 홈페이지 강의 문의)
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기존 코드를 지우고 `docs/google-apps-script.gs` 내용을 붙여 넣습니다.
4. 맨 위 `SECRET` 을 아무도 모를 긴 글자로 바꿉니다. (예: digilog-문의-8f3k2)
5. 새 문의를 메일로도 받고 싶으면 `NOTIFY_EMAIL` 에 메일 주소를 넣습니다.
6. 저장(디스크 아이콘)합니다.

## 2. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 유형 선택(톱니바퀴) → **웹 앱**
3. 실행 계정: **나**, 액세스 권한: **모든 사용자**
4. **배포** → 권한 승인(내 구글 계정) → 나오는 **웹 앱 URL** 을 복사합니다. (`https://script.google.com/macros/s/.../exec`)

## 3. Vercel에 주소 넣기
1. vercel.com → digilog-website 프로젝트 → **Settings → Environment Variables**
2. 두 개를 추가합니다.
   - `SHEET_WEBHOOK_URL` = 복사한 웹 앱 URL
   - `SHEET_SECRET` = 1-4에서 정한 SECRET 값
3. **Deployments** 에서 최신 배포를 **Redeploy** 합니다.

## 4. 확인
홈페이지 문의 페이지에서 테스트 문의를 보내고 시트에 한 줄이 생기는지 봅니다.
스크립트를 고치면 **배포 → 배포 관리 → 수정(연필) → 새 버전** 으로 다시 배포해야 반영됩니다.
