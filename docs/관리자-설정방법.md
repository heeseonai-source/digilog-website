# 관리자 페이지(/admin) 설정 방법 — 처음 한 번만

관리자 페이지는 두 가지 값이 있어야 동작해요. 둘 다 **Vercel → digilog-website → Settings → Environment Variables** 에 넣습니다.

| 이름 | 넣을 값 |
|---|---|
| `ADMIN_PASSWORD` | 관리자 페이지 로그인 비밀번호 (직접 정하기, 12자 이상 권장) |
| `GITHUB_TOKEN` | 아래 1번에서 만드는 GitHub 토큰 |

## 1. GitHub 토큰 만들기 (5분)
1. GitHub 로그인 → 오른쪽 위 프로필 → **Settings**
2. 왼쪽 맨 아래 **Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
3. 입력
   - Token name: `digilog-admin`
   - Expiration: 1년 (만료되면 같은 방법으로 새로 만들어 바꿔 넣기)
   - Repository access: **Only select repositories → digilog-website**
   - Permissions → Repository permissions → **Contents: Read and write**
4. **Generate token** → 나온 값(`github_pat_...`)을 복사합니다. 이 화면을 벗어나면 다시 볼 수 없어요.

## 2. Vercel에 넣기
1. Environment Variables → **Add**
2. `ADMIN_PASSWORD` 와 `GITHUB_TOKEN` 두 개를 추가 (환경: Production)
3. **Deployments → 최신 배포 ⋯ → Redeploy**

## 3. 사용하기
- 주소: https://digilog-website.vercel.app/admin
- 왼쪽에서 페이지를 고르고 → 고치고 → **저장하기** → 1~2분 뒤 사이트에 반영
- 사진은 **📷 사진 올리기** 로 올리면 자동으로 줄여서 저장돼요.
- 글에서 `*이렇게*` 별표로 감싸면 코랄색 강조, 줄바꿈은 그대로 반영돼요.
- 저장할 때마다 GitHub에 기록이 남아서, 실수해도 이전 상태로 되돌릴 수 있어요.

## 주의
- 비밀번호와 토큰은 다른 사람에게 알려 주지 마세요. 토큰이 새어 나갔다면 GitHub에서 바로 삭제하고 새로 만드세요.
- 수업자료로 올린 파일은 주소를 아는 사람은 열 수 있어요(주소는 추측하기 어렵게 만들어져요). 민감한 자료는 올리지 마세요.
